# StudyPilot: AI-assisted Task Breakdown & Tracking

## Project Description
StudyPilot is a simple tool that helps students break down large, intimidating assignments into small, actionable daily tasks using AI. It aims to solve the problem of procrastination by making the workflow clear and manageable.
